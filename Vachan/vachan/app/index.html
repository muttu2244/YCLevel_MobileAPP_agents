The agent team

Each agent is a prompt file plus a thin runner. In this local build the runners are built into this page (mock mode) or call your own model endpoint in LLM mode.

Self-test

The pipeline checks itself: date parsing, extractor rules, closing, de-duplication and the score formula, run against short throwaway scenarios. It works on a copy of your data and puts everything back afterwards. Run it after any change — it is the reason this build does not need a test server.

Local data

This local build persists to your browser. The real deployment uses the Postgres schema in db/schema.sql — the same tables these objects map onto.

Shared database (Supabase — optional)

This page works entirely offline. Connecting a Supabase project turns the same ledger into a shared one: the agents, your laptop and your phone all read the same rows. The schema is in db/schema.sql and the row-level security that makes a public anon key safe is in db/supabase_rls.sql. Your anon key is public by design; your password and tokens are never written into a backup.
